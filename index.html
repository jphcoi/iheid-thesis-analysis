Methodology

Pipeline Overview

  • Text Extraction: ALTO XML → Plain text
  • NER: spaCy (en_core_web_sm, fr_core_news_sm, de_core_news_sm)
  • Normalization: Multilingual entity merging (EN/FR/DE variants)
  • Visualization: Plotly interactive charts with smoothing and per-100k-words normalization
